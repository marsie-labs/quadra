# PBI-0001: Implement POST /sessions so a valid request creates a workspace, canvas and the four quadrants IS, IS NOT, DOES and DOES NOT in Supabase using a random UUIDv4 session_id, and a missing or empty feature_name is rejected with 422. Add the supabase/migrations/0001_workspace.sql schema (the workspaces, canvases and quadrants tables, created idempotently, with RLS policies that let the anon role insert and select), the Session dataclass and create_session in src/quadra/sessions.py, the SessionCreateRequest and SessionCreateResponse models and the route in src/quadra/api.py, and the runtime dependencies fastapi, nicegui and supabase in pyproject.toml. Return 201 with {session_id, status 'open', link '/sessions/{session_id}', canvas.quadrants}, within the 2000ms creation latency limit.

## Directive

## Context

Read: `docs/specs/SPEC-0001.md`

In SPEC-0001, read the API Contracts entry for POST /sessions and the Data Models entry for the workspaces, canvases and quadrants tables. Also read the constraints on UUIDv4 and the 2000ms latency, and the communication pattern between session-service and supabase in docs/architecture.md section 9 (Communication Patterns).

Configuration comes from the environment: SUPABASE_URL and SUPABASE_PUBLISHABLE_KEY for the app, SUPABASE_DB_URL for applying the migration. Tests load them from the repository's .env with python-dotenv; .env is never committed, printed or logged.

tests/api/test_sessions.py holds the two tests the Accepted ADRs name, test_create_session_success (ADR-0001) and test_create_session_validation (ADR-0002); they call the route through FastAPI's TestClient with create_session replaced by a fake, so they run without Supabase. tests/integration/ runs against the real Supabase project: its conftest.py applies supabase/migrations/0001_workspace.sql through psycopg with SUPABASE_DB_URL before the tests. Add psycopg[binary], python-dotenv and httpx to the dev dependency group.

Realtime subscriptions are deferred to a later spec; do not implement them, even though SPEC-0001's constraints mention Realtime push.
