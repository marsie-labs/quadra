# PBI-0007: In src/quadra/canvas.py, add a delete action that calls soft_delete_card and removes the card from the canvases of every connected client of the session after confirmation, using the Realtime card notifications.

## Directive

## Context

Read: `src/quadra/canvas.py and soft_delete_card in src/quadra/cards.py`

Soft-delete arrives as a Realtime UPDATE with non-null deleted_at, which the canvas must treat as removal. The row must stay in the database. Supabase-backed tests go in tests/integration/ and use its conftest.py.

## Verification

- [ ] After one participant deletes card C it is absent from both connected canvases
- [ ] C's row still exists with non-null deleted_at
- [ ] A fresh active-card query for the session excludes C

## Refinement Protocol

If removal on the other client needs behaviour the Realtime card notifications do not provide, file a discovery report rather than adding polling.
