# PBI-0014: In src/quadra/canvas.py, make pending-insertion rendering respect confirmed soft-deletions. When a Realtime soft-delete removes a card from _cards while its insertion response is still unresolved, _unconfirmed must not render that card as pending again, and the stale _pending entry must be cleaned up or ignored. The retained deletion version is the check, not mere absence from _cards. Add an integration test in tests/integration/test_canvas_delete.py that deletes an already committed card while the insert response is still held by the barrier. It must assert the card is absent from the initiating canvas during that interval, and again after the response is released.
