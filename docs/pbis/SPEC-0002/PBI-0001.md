# PBI-0001: Create src/quadra/realtime.py as the asynchronous Realtime bridge, built on supabase-py's async Realtime client inside NiceGUI's event loop. register_view(session_id, view_id, callback) opens or shares one subscription per session on the existing session and quadrant change sources and exposes readiness. Committed changes are dispatched in-process only to views of the affected session, without polling. unregister_view releases the session's subscription when its last view disconnects. Add pytest-asyncio for NiceGUI's simulated users and write tests/integration/test_realtime.py::test_push_delivery_without_polling, proving that with polling instrumented to fail, a committed change reaches a second simulated user's DOM in under 2000ms through a Supabase Realtime notification and a NiceGUI WebSocket update.
