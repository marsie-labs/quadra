# PBI-0018: In src/quadra/cards.py, add a module-level constant _PAGE_SIZE = 1000 and make list_cards read every page of the session's non-deleted cards. Order the query by id so pages are deterministic, request each page with .range(start, start + page_size - 1) (reading _PAGE_SIZE at call time so tests can monkeypatch it), and stop at the first page shorter than page_size. Keep the existing final sort (quadrant position, index, id) and the existing return type. Add an integration test in tests/integration/ that sets _PAGE_SIZE to 2, inserts 5 cards in a session plus one soft-deleted card, and asserts all 5 active cards come back in the existing order with no duplicate. The same test also covers an exact multiple of the page size (4 cards) returning all of them.

## Refinement Protocol

If the spec turns out to need updating mid-build, file a discovery report instead of editing it directly. The Contract already requires loading all persisted non-deleted cards, so a change to list_cards' signature, return type or ordering is contract-level and goes to the Contract owner. A different page size or paging strategy is code-level and stays inside this PBI. If Canvas._load would need to change to make this work, stop and report it rather than editing canvas.py.
