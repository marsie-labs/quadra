# PBI-0019: In src/quadra/cards.py, replace list_cards' offset pagination (.range) with keyset pagination. Each page is the session's non-deleted cards (deleted_at IS NULL) with id greater than the last id of the previous page (no lower bound for the first page), ordered by id ascending and limited to _PAGE_SIZE. Stop at the first page shorter than _PAGE_SIZE. Fetch one page in a small module-level helper, _fetch_page(session_id, after_id, client), that a test can wrap. Keep _PAGE_SIZE, the final sort (quadrant position, index, id) and list_cards' return type unchanged. Extend tests/integration/test_cards_pagination.py with a test that sets _PAGE_SIZE to 2, inserts 5 cards, wraps the page helper so a card from the first page is soft-deleted right after the first page is read, and asserts every card still active is returned exactly once in the existing order.
