# PBI-0013: In src/quadra/canvas.py, make _fold retain a deletion version (the deleted card's id and its deleted_at/updated_at timestamp) when it removes a soft-deleted card from _cards, and make _is_stale reject any insert, edit or relocation response or notification whose version is older than the retained deletion. This applies on every path that folds a response into the view (_submit, _save_edit, _show_confirmed and Realtime callbacks), so a delayed response arriving after a confirmed deletion can never restore the card to a connected canvas. Retained deletion versions are transient per-view state, scoped by session, and Supabase stays authoritative.
