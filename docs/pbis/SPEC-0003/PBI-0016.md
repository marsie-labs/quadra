# PBI-0016: In src/quadra/canvas.py, make Canvas._on_change ignore card notifications for the card set once the canvas is closed and has reconciled to the authoritative closed-session snapshot, so that _fold is never applied to a reconciled snapshot. A card soft-deleted before closure must not reappear when its delayed pre-deletion insert or update notification arrives after _reconcile. While closure reconciliation is still in progress, card notifications must not corrupt it, and it must still finish with the complete authoritative closed-session card set. Add an integration test in tests/integration/ for the deleted-card resurrection case.
