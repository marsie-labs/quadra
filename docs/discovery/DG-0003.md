# Discovery Graph: DG-0003
**Graph Type:** opportunity

## Core Issue

Participants need a way to conclude a collaborative session, and external agents require a secure, restricted mechanism to retrieve finalized session data.

**Impact/Value:** Enables formal session closure, prevents premature data retrieval, and integrates quadra results into external workflows.

**Discovery Method:** Analysis of project requirements for session lifecycle management and data accessibility.

## Patterns

### Pattern 1: session-closure-workflow

**Applies To:** Workspace Session Controller  
**Frequency/Recurrence:** Per-session event  
**Severity/Urgency:** Moderate  
**Confidence:** High  
**Current State:** `workspaces.status` exists and defaults to `'open'`, but nothing in the UI or the API ever changes it, and the canvas accepts card changes whatever the status.  

**Evidence Signals:**

- Participants need a way to lock a workspace and finalize results.
- Participants and the facilitator need a prominent "Finish / Close Session" action; on confirmation the status moves from `open` to `closed` and all four quadrants become read-only.

### Pattern 2: agent-retrieval-mechanism

**Applies To:** External agent harness / session results retrieval  
**Frequency/Recurrence:** On demand, per session  
**Severity/Urgency:** Moderate  
**Confidence:** High  
**Current State:** No retrieval path exists: the only API endpoint is `POST /sessions`, so an agent cannot read a session's cards by `session_id`.  

**Evidence Signals:**

- External agents need a secure mechanism to retrieve session data only after closure, with enforcement of status checks.
- A fetch for a session that is still `open` must get an explicit error (for example `409 Conflict` with "Session is still open"); a `closed` session returns every card grouped by quadrant, with its metadata and timestamps.

## Pattern Dependency Graph

`agent-retrieval-mechanism` depends on `session-closure-workflow`: the `open` → `closed` transition is what allows retrieval, and the read-only canvas guarantees the retrieved dataset no longer changes.
