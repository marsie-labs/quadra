# ADR-0007: Accept unauthenticated closure and finalized retrieval for v1

## Context

Quadra v1 has no roles or authentication. STRAT-0003 explicitly accepts knowledge of a link or identifier as sufficient access; adding facilitator privileges or authenticated retrieval would change that product boundary.

## Decision

We will allow anonymous session-link participants to close sessions and allow unauthenticated callers knowing a session UUID to retrieve closed-session data, restricting finalized retrieval by lifecycle state rather than identity.

## Alternatives Considered

- Require a facilitator role to close sessions: rejected because v1 has no role model and the handoff permits any participant to close.
- Require agent credentials for retrieval: rejected because the accepted v1 contract permits any caller with the session UUID.
- Permit retrieval of open sessions: rejected because agents must consume only finalized data.

## Consequences

### Positive

- Participants and external agents can use the feature without account provisioning.
- Open-session retrieval has a clear 409 lifecycle response.

### Negative

- Anyone obtaining a session link can irreversibly close it.
- Anyone obtaining a session UUID can read its finalized data.
- Lifecycle checks do not provide participant identity or confidentiality guarantees.
